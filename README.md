# Bigram

Bigram is a character-level language model trained on a dataset `names.txt` which generates name-like words. It looks at one character and predicts the next, using the counting probability distribution from the training set. It also trains the neural network with random weights instead of counting to predict the same. And the output gets verified by the prior.
